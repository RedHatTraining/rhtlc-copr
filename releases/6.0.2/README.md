## Usage

CLI (x86_64): tar -xzf rhtlc-linux-x86_64.tar.gz && ./rhtlc-linux-x86_64/rhtlc-linux-x86_64 --version
CLI (aarch64): tar -xzf rhtlc-linux-arm64.tar.gz && ./rhtlc-linux-arm64/rhtlc-linux-arm64 --version

GUI (x86_64): tar -xzf rhtlc-gui-linux-x86_64.tar.gz && ./rhtlc-gui-linux-x86_64/rhtlc-gui-linux-x86_64
GUI (aarch64): tar -xzf rhtlc-gui-linux-arm64.tar.gz && ./rhtlc-gui-linux-arm64/rhtlc-gui-linux-arm64

## System Requirements

- RHEL/Fedora/AlmaLinux/Rocky Linux 8 or later
- glibc 2.28 or later
- x86_64 or aarch64 architecture
