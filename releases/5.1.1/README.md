## Usage

CLI (x86_64): chmod +x rhtlc-linux-x86_64 && ./rhtlc-linux-x86_64 --version
CLI (aarch64): chmod +x rhtlc-linux-arm64 && ./rhtlc-linux-arm64 --version

GUI (x86_64): chmod +x rhtlc-gui-linux-x86_64 && ./rhtlc-gui-linux-x86_64
GUI (aarch64): chmod +x rhtlc-gui-linux-arm64 && ./rhtlc-gui-linux-arm64

## System Requirements

- RHEL/Fedora/AlmaLinux/Rocky Linux 8 or later
- glibc 2.28 or later
- x86_64 or aarch64 architecture
