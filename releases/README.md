# RHTLC Linux Release Assets

This directory contains Linux release binaries for RHTLC.

## Directory Structure

Each version has its own directory containing CLI and GUI binaries for x86_64 and aarch64 (arm64).

## Binary Information

- rhtlc-linux-x86_64: CLI (x86_64)
- rhtlc-gui-linux-x86_64: GUI (x86_64)
- rhtlc-linux-arm64: CLI (aarch64 / arm64)
- rhtlc-gui-linux-arm64: GUI (aarch64 / arm64)

## Platform Support

Built on AlmaLinux 8 (glibc 2.28), compatible with RHEL 8+, Fedora, AlmaLinux 8+, Rocky Linux 8+, CentOS Stream 8+

Architectures: x86_64 and aarch64
